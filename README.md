## 🚀 Progetti

### [NuxtShortner](https://github.com/maurodf0/NuxtShortner)
URL shortener SaaS con dashboard personale, redirect dinamici e analytics click (IP, geolocalizzazione, user agent). Tipi TypeScript generati automaticamente dal database Supabase con `supabase gen types`.
`Nuxt 3` `Supabase` `TypeScript` `Nitro`

---

### [JoinNow](https://github.com/maurodf0/JoinNow)
Applicazione gestionale multi-ruolo con autenticazione Supabase, upload avatar su Storage, aggiornamento credenziali e pannello admin riservato. Invito nuovi admin via Supabase Admin API con Service Role Key lato server.
`Nuxt 3` `Supabase` `Shadcn/ui` `TypeScript`

---

### [NuxtNote](https://github.com/maurodf0/NuxtNote)
App full stack per la gestione di note personali con autenticazione **custom da zero**: bcrypt, JWT stateless via cookie HttpOnly, validazione server-side con validator.js e autorizzazione per-utente su ogni endpoint Nitro.
`Nuxt 3` `Prisma` `MySQL` `JWT` `bcrypt`

---

### [HeadlessWP](https://github.com/maurodf0/HeadlessWP)
Portfolio personale e blog con architettura headless: Nuxt 3 come frontend, WordPress come CMS tramite REST API. Sitemap SEO generata server-side dai post WordPress, smooth scroll con Lenis, deployment su Cloudflare via NuxtHub.
`Nuxt 3` `WordPress REST API` `NuxtHub` `@nuxtjs/seo`

---

### [WPSUC — Single User Content](https://github.com/maurodf0/wpsuc)
Plugin WordPress open source per la creazione di contenuti privati per singolo utente. Architettura OOP, Custom Post Type, metabox con nonce verification, template override, accesso a 3 livelli e internazionalizzazione (i18n). Conforme agli WordPress Coding Standards e pronto per wordpress.org.
`PHP` `WordPress Plugin API` `OOP` `i18n`

## 💡 Cosa so fare

- Autenticazione custom (JWT, bcrypt, cookie HttpOnly) e integrazione con Supabase Auth
- REST API con Nitro: endpoint tipizzati per metodo HTTP, validazione, error handling
- WordPress a livello avanzato: plugin OOP, CPT, hook system, REST API, headless CMS
- Database relazionali con Prisma ORM (MySQL) e Supabase (tipi generati, RLS)
- SEO tecnica: sitemap dinamiche, meta tag, Open Graph, `@nuxtjs/seo`
- Deployment su Cloudflare Workers (NuxtHub) e Vercel
